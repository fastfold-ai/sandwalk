## Skills

Packaged instructions and scripts the agent loads on demand.

```bash
sandwalk skills add fastfold-ai/skills
sandwalk skills add fastfold-ai/skills@skills/fold
sandwalk skills find
```

In the dashboard: **Skills** — toggle installs, import from GitHub, or search [skills.sh](https://skills.sh) (install counts and security audits).

In chat: type `/` to browse skills for the active specialist and **Try** example prompts.

## MCPs

Dashboard → **MCPs** manages servers in `~/.sandwalk/mcp.json` (standard `mcpServers` shape — Cursor-compatible). Toggle catalog entries (Latch, Paperclip, Tamarind, Neurosnap, …), connect when auth is required, or add a custom URL.

Credentials stay under Integrations / keys (`sandwalk keys`).
