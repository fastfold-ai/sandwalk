## 2a. macOS app

1. Install **Sandwalk.app** from [GitHub Releases](https://github.com/fastfold-ai/sandwalk/releases) when published, or build from source:

```bash
cd apps/sandwalk-mac
./scripts/package-app.sh
open ~/Applications/Sandwalk.app
```

2. From the menu bar: **Start** the agent server.
3. Click **Open Web Dashboard**.
4. In Settings, add a model provider key if prompted.
5. Ask something in the composer, for example: `What is known about KRAS G12C inhibitors?`

Done. Details: [macOS app](/apps/macos).

## 2b. CLI

Requires Python 3.11+.

**Option A: one-liner** (installs [uv](https://docs.astral.sh/uv/) if needed, then sandwalk):

```bash
curl -fsSL https://raw.githubusercontent.com/fastfold-ai/sandwalk/main/cli/install.sh | bash
```

**Option B: uv / PyPI:**

```bash
uv tool install sandwalk
sandwalk --version
```

Optional science extras later: `uv tool install "sandwalk[all]"`.

### Get running

```bash
sandwalk setup          # models, keys, skills
sandwalk doctor         # quick health check
sandwalk serve          # API + Web UI
```

Open the dashboard: [http://127.0.0.1:8969](http://127.0.0.1:8969)

Or chat in the terminal:

```bash
sandwalk
```

| Service   | URL                     |
|-----------|-------------------------|
| Dashboard | http://127.0.0.1:8969   |
| Agent API | http://127.0.0.1:8787   |

## 3. First things to try

- Attach a file with `@` in the composer
- Type `/` for skills and MCPs
- Toggle **Plan** to draft a campaign before heavy tools
- Install skills: `sandwalk skills add fastfold-ai/skills`
