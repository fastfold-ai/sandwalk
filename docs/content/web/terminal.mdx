Press **⌘⇧T** (or click the Terminal toggle) to open a multi-tab PTY terminal docked beside or below your chat sessions.

## Interactive `sandwalk` CLI

Run `sandwalk` in any terminal tab (or in your external terminal) to access the exact same sessions, Specialists, Memory, and workspace files as the desktop app. Type `/` to open the slash-command menu (`/models`, `/specialist`, `/sandbox`, `/plan`, `/skills`, `/mcps`, `/doctor`, `/export`, `/notebook`). See [CLI Terminal](/cli/terminal).

## Interoperability with Other Coding Agents

Sandwalk reads and writes the session stores of **Claude Code**, **Codex**, **OpenCode**, **fx**, and **Hermes**:

- **Live Process Detection**: Open any of those CLIs inside a Sandwalk terminal tab; the tab header automatically displays the active agent's badge.
- **Convert to Chat (Import)**: Right-click a terminal running one of these agents and choose **Convert to chat** (or ask **Capy**). You can also distill imported transcripts into `MEMORY.md`, your Living Wiki, and Omnigraph.
- **Continue in… (Handoff & Native `--resume`)**: From any Sandwalk chat, choose **Continue in…** to write `.sandwalk/handoff-<id>.md` and launch the external CLI—or resume with synthesized native history (`claude --resume` / `codex resume`).
