- **Interactive 3D Structures**: Render `.pdb`, `.cif`, `.sdf`, and `.mol2` files directly in the 3D molecular viewer alongside pLDDT / PAE confidence plots and candidate ranking tables.
- **Reports, Plots & Notebooks**: Preview Markdown reports, CSV tables, SVG/PNG figures, and export any session or analysis as a runnable Jupyter notebook (`.ipynb`).
