---
title: Plan mode
description: Draft a research plan before running heavy tools.
---

Switch the composer from **Agent** to **Plan** when you want a campaign design first. The agent writes `plans/<slug>.md` (steps + Mermaid), fills todos, and surfaces **Build** with no Y/n gate.

In the CLI: `/plan`.
