Switch the composer from **Agent** to **Plan** (`Tab` or via the `+` menu) when you want a structured campaign design before running heavy tools or GPU jobs.

## How Plan Mode Works

1. The agent writes `plans/<slug>.md` inside the session workspace containing structured steps and an automatic **Mermaid flowchart**.
2. Steps populate the session's interactive todo list beside the chat.
3. Click **Build** in the Web UI (or toggle `/plan` back to Agent mode in the CLI) to execute the plan step by step.
