In science and ambitious engineering, changing a model, a Specialist, a skill, or a memory architecture should be **measured, not guessed**. Sandwalk includes a built-in evaluation harness (**Dashboard → Benchmarking** and `sandwalk eval` in the CLI) that runs real agent sessions end-to-end.

## Shipped Benchmark Suites

| Suite | Domain | What it measures |
|-------|--------|------------------|
| **MMLU / MMLU-Pro** | General & Scientific Reasoning | Multi-discipline knowledge and 10-option reasoning under the full agent harness |
| **ARC-C** | Scientific Reasoning | Challenge-grade natural science questions |
| **MBPP / LiveCodeBench** | Software Engineering | Code generation, sandbox execution, and test verification |
| **BixBench** | Bioinformatics & CompBio | Real-world multi-step computational biology capsules and data analysis |
| **Bio-Capybara** | Biomedical Research | Literature synthesis, target/compound lookup, and multi-tool biological workflows |

## Running Evaluations

From **Dashboard → Benchmarking**, pick one or more suites, select a model (or queue multiple models/Specialists for an A/B comparison), set concurrency and sample size, and click **Launch**.

Or run headlessly from the CLI:

```bash
sandwalk eval
```

You can also ask **Capy** in any session: *"Run a 20-question BixBench comparison between Claude Sonnet and GPT-5 with the Single-cell Analyst specialist."*
