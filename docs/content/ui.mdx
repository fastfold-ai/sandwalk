---
title: Web dashboard
description: Chat, projects, artifacts, skills, and terminal in the local web UI.
---

Open the dashboard after `sandwalk serve` or **Open Web Dashboard** from the macOS app (`http://127.0.0.1:8969` by default).

Sessions are shared with the CLI: the same chat history, workspace files, and agent runtime.

## Highlights

- **Composer** — model, effort, specialist, sandbox, Plan/Agent mode, `@` files, `/` skills & MCPs
- **Projects** — scoped workspaces with optional Agent Context
- **Artifacts** — structures, plots, and media beside the chat
- **Terminal** — multi-tab shell + interactive sandwalk CLI tab
- **Sidebar** — Models, Tools, Skills, Datasets, Specialists, MCPs, Integrations, Runtime

More product screenshots and walkthroughs live in the [repository README](https://github.com/fastfold-ai/sandwalk#web-dashboard). This page will grow as we expand the docs site.
