Configure providers during `sandwalk setup`, in the Web UI sidebar → **Models**, or with `sandwalk config`.

**Frontier / cloud:** Anthropic, OpenAI, Google Gemini, xAI (Grok), NVIDIA, OpenCode Zen, Cerebras, Groq, Fireworks AI, Amazon Bedrock.

**Local:** Ollama, Unsloth, oMLX, DS4, llama.cpp, LM Studio (OpenAI-compatible endpoints).

In the composer: pick a model, set Low / Medium / High effort, and optionally enable Fast.

**Multimodal support** (Dashboard → Models): which models accept image, PDF, audio, and video. Gemini takes the full set. See also [Multimodal](/web/multimodal).

## Amazon Bedrock (IAM)

Bedrock uses the same boto3 credential chain as the AWS CLI and LangChain `ChatBedrockConverse`. There is no Bedrock API key. Sandwalk defaults to IAM / your AWS profile and only uses access keys if you paste them.

### 1. IAM policy

Attach this to the IAM user or Identity Center permission set you log in with:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "bedrock:InvokeModel",
        "bedrock:InvokeModelWithResponseStream",
        "bedrock:ListFoundationModels",
        "bedrock:ListInferenceProfiles",
        "bedrock:GetFoundationModel"
      ],
      "Resource": "*"
    }
  ]
}
```

`InvokeModel` / `InvokeModelWithResponseStream` also cover Converse / ConverseStream. `AmazonBedrockFullAccess` works but is broader than needed.

### 2. Local login

Pick one:

- Long-lived IAM user: `aws configure` (writes the `default` profile)
- IAM Identity Center / SSO: `aws configure sso`, then `aws sso login --profile <name>`
- In Sandwalk, set **AWS profile** to that name, or leave it blank to use the default chain (`AWS_PROFILE`, `~/.aws/credentials`, instance role)

Region defaults to `us-east-1`.

### 3. Check

```bash
aws sts get-caller-identity
aws bedrock list-foundation-models --region us-east-1 --query 'modelSummaries[:3].modelId'
```

Then open **Models → Amazon Bedrock → Test**. The same session is what LangChain uses.

Listing models is not the same as being allowed to invoke them. If chat fails with `AccessDeniedException`, the identity can list the catalog but cannot call Converse on that model (marketplace agreement or a tighter IAM resource ARN).
