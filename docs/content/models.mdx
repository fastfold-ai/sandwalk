Configure providers during `sandwalk setup`, in **Dashboard → Models**, or with `sandwalk config`. Keys stay on your machine in `~/.sandwalk/config.json`.

| Kind | Supported Providers |
|------|---------------------|
| **Cloud (17 Providers)** | OpenAI, Claude (Anthropic), Gemini (Google), xAI (Grok), Kimi (Moonshot), NVIDIA, OpenCode Zen, DeepSeek, MiniMax, Mistral, Qwen Cloud, Together AI, OpenRouter, Cerebras, Groq, Fireworks AI, Amazon Bedrock |
| **ChatGPT Subscription** | **Sign in with ChatGPT** (`sandwalk login chatgpt`) — run OpenAI models on a ChatGPT Plus or Pro plan with no API key |
| **Local & Custom Endpoints** | `llama.cpp` (built-in GGUF manager), Ollama, oMLX, Unsloth, DS4, LM Studio, or **any OpenAI-compatible endpoint** (vLLM, SGLang, TGI, LiteLLM, custom HPC servers) |

Local endpoints are auto-discovered from `/v1/models` or Ollama's `/api/tags`. Add custom endpoints with **Add Local LLM** in **Dashboard → Models**, or in the CLI with `/models`.

## Sign in with ChatGPT

OpenAI models can run on your existing ChatGPT Plus or Pro subscription without an API key. In the app, click **Continue with ChatGPT** under **Dashboard → Models**, or run in a terminal:

```bash
sandwalk login chatgpt            # opens browser; stores tokens in ~/.sandwalk/chatgpt-auth.json
sandwalk login status
sandwalk logout chatgpt
```

Models then appear under **ChatGPT plan** in the model picker.

## Amazon Bedrock (IAM)

Bedrock uses the same `boto3` credential chain as the AWS CLI and LangChain `ChatBedrockConverse`. Sandwalk defaults to IAM / your AWS profile (`AWS_PROFILE`, `~/.aws/credentials`, or instance role):

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "bedrock:InvokeModel",
        "bedrock:InvokeModelWithResponseStream",
        "bedrock:ListFoundationModels",
        "bedrock:ListInferenceProfiles",
        "bedrock:GetFoundationModel"
      ],
      "Resource": "*"
    }
  ]
}
```

Verify locally with `aws sts get-caller-identity`, then click **Models → Amazon Bedrock → Test** in the Dashboard.
