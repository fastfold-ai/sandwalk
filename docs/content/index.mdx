**sandwalk** is a self-hosted science agent for multi-step research across 190+ tools, database APIs, skills, MCPs, and sandboxes. Use the terminal, the web dashboard, or the macOS app — they share the same sessions and workspace.

## Why sandwalk

- **CLI ↔ web** — one agent session, two surfaces
- **Plan mode** — draft research plans before heavy tool runs
- **Multimodal** — `@`-attach images, PDFs, audio, and video (Gemini takes the full set)
- **Local + cloud compute** — Local Sandbox or Modal / Fastfold Cloud GPUs
- **Skills & MCPs** — install from GitHub or [skills.sh](https://skills.sh); Cursor-compatible `mcp.json`
