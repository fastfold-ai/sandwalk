title: Skills
description: Install guided workflows from GitHub or skills.sh.
---

Packaged instructions and scripts the agent loads on demand.

```bash
sandwalk skills add fastfold-ai/skills
sandwalk skills add fastfold-ai/skills@skills/fold
sandwalk skills find
```

In the Web UI: **Skills**. Toggle installs, import from GitHub, or search [skills.sh](https://skills.sh) (install counts and security audits).

In chat: type `/` to browse skills for the active specialist and **Try** example prompts.

CLI details: [Command reference → Skills](/cli/skills).
