Skills are packaged `SKILL.md` instructions, reference schemas, and scripts that agents load on demand.

## 1. Install from `skills.sh` or GitHub

In **Dashboard → Skills**, browse the public [skills.sh](https://skills.sh) leaderboard (with install counts and security audits), toggle installed skills, or install from any GitHub repository:

```bash
sandwalk skills add fastfold-ai/skills
sandwalk skills add fastfold-ai/skills@skills/fold
sandwalk skills find
```

## 2. Crystallize Your Own Skills from Memory, Wiki & Omnigraph

You can turn what your workspace has learned into a reusable Skill (`~/.sandwalk/skills/<slug>/SKILL.md` + `references/{schema.pg,queries.gq,wiki-digest.md}`):

- **From the UI**: In **Dashboard → Memory & Wiki**, click **Create Skill** in the top header (or **To Skill** inside any Living Wiki page or Knowledge Graph view).
- **From Chat or Capy**: Ask any agent *"Create a skill from what we know about oral GLP-1R"* (calls `memory.create_skill` or `capy.create_skill_from_memory`).
