In interactive mode, type `/tools` to inspect enabled tools by category.

## Tool Tiers: Core vs. Domain Extra

To keep the system prompt fast and KV-cache friendly, Sandwalk splits its ~190 registry tools into two tiers:

1. **Always-On Core Tools (`core`)**:
   - Workspace & Sandbox: `shell.run`, `files.list_directory`, `files.read_file`, `files.write_report`, `files.write_csv`, `environment.install_package`, `environment.list_packages`, `skills.manage`
   - Primary Scientific Lookups: `literature.pubmed_search`, `data_api.uniprot_lookup`, `data_api.opentargets_search`
   - Compounding Memory, Wiki & Omnigraph (`memory.*`): `memory.mutate`, `memory.session_search`, `memory.wiki_list`, `memory.wiki_read`, `memory.wiki_write`, `memory.select_cookbook`, `memory.graph_upsert_node`, `memory.graph_record_claim`, `memory.graph_cookbook_query`, `memory.graph_branch`, `memory.distill_session`, `memory.create_skill`
2. **Domain Extra Tools (`extra`)**:
   - Medicinal chemistry (`rdkit`, SAR, ADMET), single-cell & genomics (`scanpy`, `cellxgene`, GWAS coloc, TCGA), clinical trials, protein structure & docking, pathways, and statistics—enabled per **Specialist** or toggled in **Dashboard → Tools**.
