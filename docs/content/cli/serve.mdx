---
title: Serve
description: Start the local agent API and Web UI from the CLI.
---

```bash
sandwalk serve
```

| Service   | Default URL             |
|-----------|-------------------------|
| Agent API | http://127.0.0.1:8787   |
| Dashboard | http://127.0.0.1:8969   |

Best for using the [Web UI](/web/composer) while keeping the CLI as the process supervisor. On macOS you can use [Sandwalk.app](/apps/macos) instead.

```bash
sandwalk auth generate   # optional
sandwalk auth enable
```
