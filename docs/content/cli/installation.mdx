---
title: Installation
description: Install or upgrade the Sandwalk CLI and desktop app.
---

Requires Python 3.11+ on macOS or Linux.

## 1. One-Liner Install (`sandwalk.sh/install.sh`)

```bash
curl -fsSL https://sandwalk.sh/install.sh | bash
sandwalk setup
sandwalk desktop
```

The installer detects macOS or Linux, bootstraps [`uv`](https://docs.astral.sh/uv/) if needed, installs `sandwalk` into an isolated tool environment from the latest GitHub Release tag (`git+https://github.com/fastfold-ai/sandwalk.git@<tag>#subdirectory=cli`), and puts `sandwalk` on your `PATH`.

- `sandwalk setup` walks through providers, API keys (or **Sign in with ChatGPT**), and a default model.
- `sandwalk desktop` downloads and installs the native desktop app (`.dmg` on macOS or `.deb` on Ubuntu).

### Pin a Version or Pre-Release

```bash
# Install the newest release (including pre-releases)
curl -fsSL https://sandwalk.sh/install.sh | bash -s -- --pre

# Install a specific release version
curl -fsSL https://sandwalk.sh/install.sh | bash -s -- --version 0.1.11

# Install from a specific git branch or commit
curl -fsSL https://sandwalk.sh/install.sh | bash -s -- --ref main
```

---

## 2. Install from Source Checkout

```bash
git clone https://github.com/fastfold-ai/sandwalk.git
cd sandwalk/cli
uv sync --extra all
uv run sandwalk --version
```

---

## 3. Upgrade

```bash
sandwalk upgrade
```

Or re-run `curl -fsSL https://sandwalk.sh/install.sh | bash` to update to the latest release.
