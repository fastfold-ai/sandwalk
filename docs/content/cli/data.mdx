---
title: Data
description: Pull and manage local scientific reference corpora (DepMap, MSigDB, STRING).
---

```bash
sandwalk data list
sandwalk data pull-all
```

In interactive mode, type `/data` (or manage datasets in **Dashboard → Datasets**).

## Built-in Local Corpora (`~/.sandwalk/data/`)

| Dataset | Description | Typical Size |
|---------|-------------|--------------|
| **DepMap (`depmap`)** | Cancer dependency map (CRISPR Chronos gene effects, expression, mutations, and cell-line metadata) | ~650 MB |
| **MSigDB (`msigdb`)** | Molecular Signatures Database Hallmark, Reactome, KEGG, and GO gene sets for enrichment analysis | ~45 MB |
| **STRING (`string`)** | Human protein–protein interaction network and confidence scores | ~320 MB |

Once pulled, scientific tools query these corpora locally on disk with zero network latency.
