---
title: One-shot
description: Run a single query from scripts, pipelines, or CI and exit.
---

```bash
sandwalk "What is known about KRAS G12C inhibitors?"
sandwalk --smiles "CCO" "Profile this compound"
```

One-shot mode runs the full Sandwalk agent (including your configured default model, Specialist, Memory snapshot, skills, and sandbox) for a single turn, prints the response and generated artifact paths, and exits with code `0` on success.
