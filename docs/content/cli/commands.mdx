### Interactive slash commands

| Slash | Description |
|-------|-------------|
| `/help` | List commands and shortcuts |
| `/model` | Switch model / provider |
| `/effort` | Set Effort / Fast (thinking) for the active model |
| `/sandbox` | Pick Local / Modal compute (+ edit base image) |
| `/plan` | Toggle Plan mode (sessions start in Agent mode) |
| `/specialist` | Set / clear / list specialists |
| `/usage` | Session token and cost usage |
| `/tools` | Browse tools |
| `/skills` | Installed skills |
| `/skills-add` / `/skills-find` / `/skills-upgrade` / `/skills-remove` | Skill install lifecycle |
| `/data` | Datasets |
| `/keys` | API key status (`set-moonshot`, `set-compatible`, …) |
| `/mcp` | MCP servers |
| `/model-manager` | OpenAI-compatible profiles |
| `/doctor` | Readiness diagnostics |
| `/interrupt` | Stop active generation (`!` to force) |
| `/export` / `/notebook` | Export transcript / Jupyter |
| `/new` / `/sessions` / `/resume` | Session lifecycle |
| `/exit` | Leave the terminal |

```bash
sandwalk --help
```

More detail: [Terminal](/cli/terminal) · [Plan mode](/cli/plan) · [Sandbox](/cli/sandbox).
