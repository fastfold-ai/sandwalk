title: Skills
description: Find, install, upgrade, and list skills from the CLI.
---

```bash
sandwalk skills list
sandwalk skills find
sandwalk skills add fastfold-ai/skills
sandwalk skills add fastfold-ai/skills@skills/fold
```

In interactive mode, type `/skills`, `/skills-add`, or `/skills-find`.

## Skill Resolution Tiers on Disk

Sandwalk resolves skills across three local directories (highest priority first):

| Tier | Path | Source |
|------|------|--------|
| **1. Global & Crystallized** | `~/.sandwalk/skills/<slug>/SKILL.md` | Skills installed via `sandwalk skills add` or crystallized from your Memory, Living Wiki & Omnigraph via `memory.create_skill` |
| **2. Catalog (`skills.sh`)** | `~/.sandwalk/.claude/skills/<slug>/SKILL.md` | Public catalog skills installed from [skills.sh](https://skills.sh) |
| **3. Built-in (`bundled`)** | `cli/src/skills/<slug>/SKILL.md` | Core skills shipped with Sandwalk (`omnigraph`, `knowledge-steward`, `boltz`, ` scientific-plotting`, `sites-hosting`, etc.) |

See also [Skills](/skills) and [Memory, Living Wiki & Omnigraph](/memory).
