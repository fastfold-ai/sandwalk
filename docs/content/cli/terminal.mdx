---
title: Terminal
description: Interactive sandwalk REPL with slash commands and shared sessions.
---

```bash
sandwalk
```

Best for interactive development: chat, tools, skills, and plan mode without leaving the terminal. Shares sessions with the Web UI.

New here? Start with the root [Quick Start](/quickstart).

Type `/` for slash-command autocomplete. Model, specialist, and sandbox appear in the status bar.

| Command | Purpose |
|---------|---------|
| `/help` | List commands |
| `/plan` | Toggle Plan mode (see [Plan mode](/cli/plan)) |
| `/tools` | Browse curated tools |
| `/skills` | Installed skills |
| `/data` | Local datasets |

See also [Command reference](/cli/commands).
