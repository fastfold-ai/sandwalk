---
title: Plan mode
description: Toggle Plan mode from the CLI with /plan. Sessions start in Agent mode.
---

```bash
sandwalk
# then:
/plan
```

## Defaults

Interactive CLI sessions **always start with Plan mode off** (Agent mode), even if Plan mode was left on in the Web UI. That keeps terminal runs executable by default.

`/plan` toggles Plan ↔ Agent and saves the preference for the rest of the session. The status bar shows a mustard **plan mode** label only when Plan mode is active.

## Behavior

Same idea as [Plan mode in the Web UI](/web/plan-mode):

- The agent drafts a campaign under `plans/<slug>.md` (steps + Mermaid flowchart).
- Todos are filled from the plan.
- Heavy tool execution waits until you switch back to Agent mode (`/plan` again) or continue from the Web UI **Build** action.
