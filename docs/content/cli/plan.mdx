---
title: Plan mode
description: Toggle Plan mode from the CLI with /plan.
---

```bash
sandwalk
# then:
/plan
```

Same behavior as [Plan mode in the Web UI](/web/plan-mode): the agent writes `plans/<slug>.md`, fills todos, and you switch back to Agent (or Build in the UI) when ready. The status bar shows plan mode when active.
