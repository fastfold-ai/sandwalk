---
title: macOS app
description: Menu-bar entrance to the local agent server and dashboard.
---

**Sandwalk.app** is the simplest way in on Mac. Start and stop the local agent server from the menu bar, open the Web UI, and use Settings for ports, models, tools, and skills.

For the shortest path, see [Quick Start](/quickstart).

```bash
cd apps/sandwalk-mac
./scripts/package-app.sh
open ~/Applications/Sandwalk.app
```

Or install from [GitHub Releases](https://github.com/fastfold-ai/sandwalk/releases) when published.

Server settings also live under Application Support; runtime config remains in `~/.sandwalk/` (see [Configuration](/configuration)).

From there, most day-to-day work happens in the [Web UI](/web/composer).
